🎯 Project: Sentiment Analysis & Trend Dashboard

This project is a real-time web application that analyzes user-provided text (e.g., comments or reviews) for sentiment using Hugging Face's Transformers library. It classifies input as Positive, Negative, or Neutral and stores the results in a local SQLite database. The frontend, built with Streamlit and Plotly, displays sentiment trends over time with interactive visualizations and a searchable comment history table.

🎯 Tech Stack:

Python 3, 
Streamlit (UI), 
Hugging Face Transformers (sentiment-analysis pipeline), 
SQLite (database), 
Plotly & Pandas (charts & data management).

🎯 Features:

Real-time sentiment classification, 
Persistent storage of comments and predictions, 
Line chart of sentiment trends over time, 
Filterable data table of all entries.
